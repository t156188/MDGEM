# 文档标题

一句话简介:这份文档要解决什么问题 / 记录什么内容。

## 背景

写下上下文、动机或前置信息。

## 正文

用小标题把内容分块,便于在侧栏大纲里跳转。

- 要点一
- 要点二
- 要点三

> 需要强调的话放在引用块里。

### 代码示例

```bash
echo "在这里放命令或代码"
```

## 结论 / 下一步

- [ ] 待办一
- [ ] 待办二
